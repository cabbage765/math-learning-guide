製作紀錄

這個網站是在與 Claude Code 的對話中做出來的。以下是整個過程的紀錄。

1. 設定回答語言

請 Claude 一律用繁體中文（台灣用語）回答，專有名詞保留英文。這個偏好寫進了使用者層級的 CLAUDE.md，之後每個專案的對話都會套用。

2. 連上 Claude in Chrome

從 Chrome 線上應用程式商店安裝 Anthropic 的 Claude 擴充功能並登入，讓 Claude 可以操作瀏覽器，例如填寫驗證碼、檢查網頁。

3. 安裝開發軟體

用 Windows 內建的 winget 在背景安裝，全部使用預設選項：

軟體用途
VS Code編輯程式碼
Node.js LTS執行 JavaScript 工具
Git版本控制
GitHub CLI（gh）從終端機操作 GitHub

4. 完成 GitHub 授權

  1. Claude 在背景執行 gh auth login --web，取得一次性驗證碼。
  2. Claude 用 Chrome 打開 github.com/login/device，把驗證碼填好。
  3. 由本人按下 Continue 與 Authorize，完成授權。
  4. Claude 設定 Git 透過 GitHub CLI 驗證身分，之後 push、pull 不用再輸入密碼。

5. 整理對話、架站上線

  • 把「孩子數學不及格」的建議整理成網站，並特別突出第二點「每天少量、固定，比週末狂補有效」。
  • 純 HTML 與 CSS，不需要建置工具，支援手機與深色模式。
  • 程式碼放在公開的 GitHub repo，用 GitHub Pages 發布成公開網址。
  • 上線後用 Claude in Chrome 逐頁檢查。
本站整理自與 Claude 的對話，內容僅供參考，不能取代老師或專業人員的評估。
